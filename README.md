# GMLiva — Final College Prototype

GMLiva is a static, deployment-ready prototype for a personal social media and content assistant.

## Included
- Photo upload (1–3 images) with visible thumbnails and selection
- Reliable browser-only demo analysis and content package
- Idea-to-Content Studio
- Three separate real Pose Studio photos
- Audience/user section
- Content Planner
- Personal-assistant positioning and user approval messaging
- Green + soft pink premium visual theme
- Simple GM L logo
- No paid API required for the core demo

## Deploy
The project is intentionally simple:
- `index.html` must remain in the repository root.
- Keep the `assets` folder beside `index.html`.
- On GitHub: upload both `index.html` and the `assets` folder.
- On Vercel or Netlify: deploy the project folder as a static site.

No build command is required.

## Important
The Pose Studio images are examples supplied for the college demo. The site does not claim that it generated those exact photographs.

The photo analysis uses a local fallback/demo experience so the presentation does not depend on API credits.
